# Reflection Assignment: Logic Gates Snapshot

**Length:** 200–300 words. **Format:** PDF or Markdown. **Due:** Next class after Session 3.

## What to do (simple steps)
1) Pick ONE scenario (choose from below or make your own):
   - Two-factor login (password AND code)
   - Alarm system (motion OR window sensor)
   - Toggle feature (dark mode XOR switch)
   - Traffic light safety (green AND NOT pedestrian button)
2) Draw or describe the gates and label the inputs/outputs in one or two sentences.
3) Make a small truth table (2 inputs → 4 rows). Fill it in and explain ONE row in plain language.
4) Say why it matters if the logic is wrong (what could break or be unsafe).
5) End with one thing you learned or one question you still have.

## Template you can copy
- Scenario: ___________________________
- Inputs: A = ________, B = ________, Output = ________
- Gate(s): AND / OR / NOT / XOR / NAND / NOR / XNOR (circle or type)
- Truth table (example shape):  
  | A | B | Output |  
  | 0 | 0 |   ?    |  
  | 0 | 1 |   ?    |  
  | 1 | 0 |   ?    |  
  | 1 | 1 |   ?    |  
- One-row explanation: “When A = __ and B = __, the output is __ because ______.”
- Why correctness matters: ______________________________________________
- One learning or question: _____________________________________________

## Grading (12 points)
- **Accuracy (4 pts):** Truth table matches the gate(s); inputs/outputs labeled.
- **Connection (4 pts):** Clear link between the scenario and the gate behavior.
- **Clarity (2 pts):** Plain language; readable table/diagram.
- **Professionalism (2 pts):** Within length; on time; effort shown.

## Quick tips
- If you are stuck, start by filling the table with guesses, then adjust after checking the gate definitions.
- Keep variables short and obvious (`A = password correct`, `B = code correct`, `Output = unlock`).
- Use the slides’ examples if you need a model—simple is fine.
