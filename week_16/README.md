# Week 16 – From Logic Gates to Python Conditionals

## Topics
- Recapping binary logic and truth tables (AND, OR, NOT, XOR)
- Boolean values and comparison operators in Python
- Logical operators (`and`, `or`, `not`) and how they mirror gates
- Control flow patterns: `if`, `if/else`, `elif`, and nested checks
- Tracing execution and avoiding common mistakes (missing `else`, wrong indentation)

## Learning Objectives
- Translate simple gate logic into Python conditionals and predict outputs.
- Write clear `if`/`elif`/`else` blocks that handle mutually exclusive cases.
- Use comparisons (`==`, `!=`, `<`, `<=`, `>`, `>=`) to build boolean expressions.
- Explain truthy/falsy values and how Python short-circuits `and`/`or`.
- Debug conditional logic by printing intermediate boolean results.

## Tips
- Write out expected True/False for each expression before running the cell.
- Use `print()` to show the value of intermediate boolean expressions while debugging.
- If an `if` block feels long, consider using `elif` for mutually exclusive cases instead of multiple `if` statements.
